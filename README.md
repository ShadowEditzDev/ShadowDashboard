# 🌑 𝑆𝘩𝑎𝑑𝑜𝘸 • 影-Bot

> ⚔️ **Rise from the shadows. Rule your server.**

🌑 **𝑆𝘩𝑎𝘥𝑜𝘸 • 影-Bot** is an all-in-one Discord bot built to make server management **easier, cleaner, and more fun.**

### ✨ Features

🛡️ **Moderation** — Warn, kick, ban, timeout, clear, lock & unlock
⭐ **XP & Levels** — Earn XP, level up, rank up & compete on the leaderboard
🎮 **Games** — Anime character, movie & song guessing games
🗳️ **Polls** — Create interactive polls for your community
🔐 **Verification** — Simple server verification system
🎭 **Self Roles** — Let members choose their own roles
📊 **Dashboard** — Manage and monitor ShadowBot from a clean web interface
